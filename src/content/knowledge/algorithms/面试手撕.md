## 给你一个 严格递增 的整数数组 rungs ，用于表示梯子上每一台阶的 高度 。当前你正站在高度为 0 的地板上，并打算爬到最后一个台阶。另给你一个整数 dist 。每次移动中，你可以到达下一个距离你当前位置（地板或台阶）不超过 dist 高度的台阶。当然，你也可以在任何正 整数 高度处插入尚不存在的新台阶。返回爬到最后一阶时必须添加到梯子上的 最少 台阶数。

```cpp
题目理解
数组 `rungs` 严格递增，起点高度 0。每次最多向上跳 `dist`。如果相邻两个台阶高度差大于 `dist`，就需要插入新台阶，求**最少插入台阶数量**。

> 公式：两个高度 `prev` 和 `cur`，差值 `delta = cur - prev`
> 需要新增台阶数：`(delta - 1) / dist - 1`，当 `delta > dist` 才需要加。
#include <bits/stdc++.h>
int cal(vector<int>& nums, int dist) {
    int res = 0;
    int cur = 0;
    for (int h : nums) {
        int d = h - cur ;
        res += (d - 1) / dist;
        cur = h ;
    }
    return res ;
}
```

## 手撕LRU

```cpp
#include <unordered_map>
struct Node {
    int key;
    int value;
    Node* prev;
    Node* next;
    Node(int k, int v): key(k), value(v), prev(nullptr), next(nullptr) {}
};
class LRUCache {
private:
    std::unordered_map<int, Node*> mp;
    int capacity;
    Node* dummy;

    Node* getNode(int key) {
        auto it = mp.find(key);
        if (it == mp.end()) {
            return nullptr;
        }
        Node* node = it->second;
        remove(node);
        pushFront(node);
        return node;
    }
    void remove(Node* x) {
        x->prev->next = x->next;
        x->next->prev = x->prev;
    }
    void pushFront(Node* x) {
        x->prev = dummy;
        x->next = dummy->next;
        x->prev->next = x;
        x->next->prev = x;
    }
public:
    LRUCache(LRUCache&) = delete;
    LRUCache& operator=(const LRUCache&) = delete;
    LRUCache(int cap) : capacity(cap) {
        dummy = new Node(0, 0);
        dummy->prev = dummy;
        dummy->next = dummy;
    }
    int  Get(int key) {
        auto* node = getNode(key);
        if (!node) return -1;
        return node->value;
    }
    void Put(int key, int value )  {
        auto* node = getNode(key);
        if (node != nullptr) {
            node->value = value;
            return ;
        }
        node = new Node(key, value);
        mp[key] = node;
        pushFront(node);
        if(mp.size() > capacity) {
            auto* backnode = dummy->prev;
            mp.erase(backnode->key);
            remove(backnode);
            delete backnode;
        }
    }
    ~LRUCache() {
        auto *cur = dummy->next;
        while(cur != dummy) {
            auto* del = cur;
            cur = cur->next;
            delete del;
        }
        delete dummy;
    }
};
```

# 题目：允许一次区间反转的最长连续target

> 二进制数组，**最多可以反转1次连续子区间（区间内0↔1，0变1、1变0，也可以选择不反转）**，求反转后，数组中最长连续等于 `target` 的子数组长度。

暴力思路：枚举所有`[L,R]`区间模拟翻转，再扫描数组统计最长target，复杂度$O(n^2)$，大数据超时。最优解：**Kadane最大子数组，O(n)时间、O(1)空间**。

## 核心转化思路

翻转一段区间`[L,R]`，对target来说，每个位置有收益/损失：

- 若`nums[i] == target`：本来就是目标值，一旦被翻转 → 不再是target，收益 = `-1`
- 若`nums[i] != target`：本来不是目标值，一旦被翻转 → 变成target，收益 = `+1`

设收益数组 $a[i]$：

$$
a[i]=
\begin{cases}
-1 & nums[i]==target \\
1 & nums[i]!=target
\end{cases}
$$

翻转区间$[L,R]$的总收益 = $\sum_{i=L}^{R}a[i]$。

- 总和>0：翻转这段区间，整体可以增加target数量；
- 总和≤0：翻转没有收益，选择**不翻转**。

解题分为两步：

1. **base**：不做任何翻转，原数组中最长连续target的长度。
2. **maxGain**：使用Kadane算法求收益数组`a`的**最大子数组和**（翻转某一段区间能拿到的最大净收益）。

最终答案：
$$\boldsymbol{ans = base + \max(maxGain,\ 0)}$$

> 如果`maxGain ≤ 0`，取0，等价于不翻转任何区间。

## Kadane算法原理

维护两个变量：

- `dp`：**以当前下标结尾的最大子数组和**
  $$dp = \max(a[i],\ dp+a[i])$$
  含义：要么从当前元素新开一段区间；要么把当前元素接在前面的子数组后面。
- `maxGain`：全局记录遍历过程中`dp`的最大值。

## C++ 代码（面试手撕版）

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findMax(vector<int>& nums, int target) {
        // 1. base：不翻转，原数组最长连续target
        int base = 0;
        int cur = 0;
        for(int x : nums) {
            if(x == target) {
                cur++;                // 当前这个数就是target，连续长度+1
                base = max(base, cur);// 更新全局最长
            } else {
                cur = 0;              // 当前数不是target，连续断了！重置当前连续计数为0
            }

        }

        // 2. Kadane求收益数组最大子数组和，得到maxGain
        int pre = 0, Max = 0;
        for (int x : nums) {
            int val = (x == target) ? -1 : 1;
            pre = max(pre + val, val);
            Max = max(Max, pre);
        }
        return base + Max;
    }
};
```

## 把石头分成两个子集，求两组和的最小差值。**不限制两组元素数量，只要求所有元素必须分配**。

> 总和 \(total = sum(nums)\)
> 子集 A 和为 S，子集 B 和为 \(total - S\)
> 差值 \(= |total - S - S| = |total - 2S|\)
> 目标：找到**不超过 total/2 的最大 S**，代入得到最小差值。

```cpp
//dp[j] 若干石头， 凑出总和等于j
//背包容量 total / 2
//initialize: dp[0] = true
//从target往下找最大的j, 满足dp[j] = true
//ans = total - 2 * j
#include <vector>
#include <numeric>
using namespace std;
int minSubSetDiff(vector<int>& ss) {
    int total = accumulate(ss.begin(), ss.end(), 0);
    int target = total / 2;
    vector<bool> dp(target + 1, false);
    dp[0] = true;

    for(int x : ss) {
        //01背包， 倒序
        for (int j = target; j >= x; j--) {
            dp[j] = dp[j] || dp[j - x];
        }
    }
    int b = 0;
    for(int j = target; j >= 0; j--) {
        if (dp[j]) {
            b = j;
            break;
        }
    }
    return total - 2 * b;
}
```

## 给定一个二叉树，如何求树中两个节点的最近公共祖先 (LCA)

> 最近公共祖先：两个节点 p、q，深度最大、同时是 p 和 q 祖先的节点。

**递归后序解法**
函数返回值含义：返回当前子树中找到的 p 或者 q；找不到返回 nullptr。

1. 如果 root 为空，或者 root 等于 p 或者 root 等于 q，直接返回 root；
2. 递归左子树得到 left，递归右子树得到 right；
3. - left 非空 && right 非空：说明 p、q 分别分布在左右子树，**root 就是 LCA**，返回 root；
   - left 不为空，right 为空：返回 left（p/q 都在左子树）
   - right 不为空，left 为空：返回 right（p/q 都在右子树）

```
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    if(!root || root == p || root == q) return root;
    TreeNode* left = lowestCommonAncestor(root->left,p,q);
    TreeNode* right = lowestCommonAncestor(root->right,p,q);
    if(left && right) return root;
    return left ? left : right;
}
```

## 一个 m*n 的矩阵，从左上角走到右下角，每次只能向右或向下走，如何计算有多少种不同的路径？

> LeetCode 62 不同路径。只能向右、向下。

### 组合数学思路（最优）

一共要向下走 \(m‑1\) 步，向右走 \(n‑1\) 步；总步数 \((m‑1)+(n‑1)=m+n‑2\)。
总路径数等价于总步数中选 \(m‑1\) 步向下（剩余向右）：

\(C_{m+n‑2}^{m‑1}\)

### DP 思路

dp [i][j]：走到 i,j 位置的路径数。

- 第一行所有点：只能从左边过来，`dp[0][j]=1`
- 第一列所有点：只能从上边过来，`dp[i][0]=1`
  转移：`dp[i][j] = dp[i‑1][j] + dp[i][j‑1]`；上面来 + 左边来。
  可以滚动数组压缩空间为一维。

时间\(O(mn)\)，空间可以压到\(O(n)\)。

## 手写线程池（C++）

核心组件：

1. 任务队列 `std::queue<std::function<void()>>`
2. 线程数组 `std::vector<std::thread>`
3. 互斥锁 `std::mutex`
4. 条件变量 `std::condition_variable`
5. 标志位 `bool stop_` 控制线程池关闭

核心逻辑：

- 构造：创建 N 个工作线程，线程循环阻塞等待任务；
- `submit`：提交任务，上锁放入队列，notify_one 唤醒一个线程；
- 工作线程循环：wait 等待任务；拿到任务解锁，执行任务；
- 析构：stop 置 true，notify_all，join 所有线程。

最简可运行版本：

```cpp
        for(int i=0; i<n; i++){
            workers_.emplace_back([this](){
                while(true){
                    std::function<void()> task;
                    {
                        std::unique_lock<std::mutex> lock(mtx_);
                        cv_.wait(lock, [this](){
                            return stop_ || !tasks_.empty();
                        });
                        if(stop_ && tasks_.empty()) return;
                        task = std::move(tasks_.front());
                        tasks_.pop();
                    }
                    task();
                }
            });
        }
    }

    template<typename F>
    void submit(F&& f){
        {
            std::lock_guard<std::mutex> lock(mtx_);
            tasks_.push(std::forward<F>(f));
        }
        cv_.notify_one();
    }

    ~ThreadPool(){
        {
            std::lock_guard<std::mutex> lock(mtx_);
            stop_ = true;
        }
        cv_.notify_all();
        for(auto &t : workers_){
            t.join();
        }
    }
private:
    std::vector<std::thread> workers_;
    std::queue<std::function<void()>> tasks_;
    std::mutex mtx_;
    std::condition_variable cv_;
    bool stop_;
};

//使用
int main(){
    ThreadPool pool(4);
    pool.submit([](){std::cout<<"task1\n";});
    return 0;
}
```

## 二维矩阵，找连通块，内部全 0，边界全是 1（被 1 包围）

题意：找出**被 1 完全包围的 0 连通块**，边界必须全部是 1；边缘上的 0 不算（挨着矩阵外边界，外面没有 1 包围）。

> 等价题目：**封闭岛屿** LeetCode 1254。

### 思路

1. 矩阵**四周的 0**一定不属于封闭岛，先从四条边界做 DFS/BFS，把所有连通的 0 标记为已访问；
2. 遍历矩阵内部剩下的格子，遇到未访问的 0，就是目标连通块，计数；
3. DFS/BFS 遍历连通块，标记访问。

关键点：

- 边界的 0 直接排除，因为没有被 1 包围；
- 连通是上下左右四连通（题目没说对角，默认四连通）；
- 可以原地修改矩阵（把访问过的 0 改成 2），省去额外 visited 数组节省内存。

伪代码：

```cpp
int closedIsland(vector<vector<int>> grid) {
    int m = grid.size(), n = grid[0].size();
    // 1. 淹掉四条边上所有0连通块
    for(int i=0;i<m;i++){
        for(int j=0;j<n;j++){
            if((i==0||i==m-1||j==0||j==n-1) && grid[i][j]==0){
                dfs(grid,i,j);
            }
        }
    }
    int cnt=0;
    // 2. 内部找剩下0连通块
    for(int i=1;i<m-1;i++){
        for(int j=1;j<n-1;j++){
            if(grid[i][j]==0){
                dfs(grid,i,j);
                cnt++;
            }
        }
    }
    return cnt;
}
void dfs(grid,i,j){
    if越界 || grid[i][j] !=0 return;
    grid[i][j]=2; //标记已访问
    dfs(i+1,j);dfs(i-1,j);dfs(i,j+1);dfs(i,j-1);
}
```

```cpp
#include <mutex>
class Singleton{
public:
    static Singleton* getInstance() {
        // 第一次检查：无锁，快速判断是否已经创建
        if (instance == nullptr) {
            std::lock_guard<std::mutex> lock(mtx);
            // 第二次检查：拿到锁之后再判断，防止多个线程同时进入第一层if
            if (instance == nullptr) {
                instance = new Singleton();
            }
        }
        return instance;
    }

    // 可选：程序退出手动释放
    static void destroy() {
        std::lock_guard<std::mutex> lock(mtx);
        if(instance != nullptr) {
            /*
            `delete instance;` 只是**释放堆内存、调用对象析构函数**，但**变量 `instance` 本身的值不会自动变成 nullptr，它会变成野指针**。所以要手动写 `instance = nullptr;`。
            */
            delete instance;
            instance = nullptr;
        }
    }

private:
    Singleton() = default;
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;

    static std::mutex mtx;
    // 关键！C++11及以后要用atomic，防止指令重排
    static std::atomic<Singleton*> instance;
};
```

## 手撕：栈排序，仅允许一个辅助空栈，不能用别的数据结构

```go
package main

import "fmt"

type Stack []int

func (s *Stack) Push(v int) {*s = append(*s, v)}
func (s *Stack) Pop() int {
	top := (*s)[len(*s)-1]
	*s = (*s)[:len(*s)-1]
	return top
}
func (s *Stack) Peek() int {return (*s)[len(*s)-1]}
func (s *Stack) Empty() bool {return len(*s)==0}

func sortStack(s Stack) Stack {
	var tmp Stack
	for !s.Empty() {
		cur := s.Pop()
		for !tmp.Empty() && tmp.Peek() > cur {
			s.Push(tmp.Pop())
		}
		tmp.Push(cur)
	}
	return tmp
}

func main() {
	st := Stack{3,1,4,2}
	res := sortStack(st)
	for !res.Empty() {
		fmt.Println(res.Pop())
	}
}
```

```cpp
// 只允许额外一个栈辅助，把栈从小到大排序
stack<int> sortStack(stack<int> s) {
    stack<int> tmp;
    while (!s.empty()) {
        int cur = s.top();
        s.pop();
        // 把tmp中大于cur的元素全部倒回原栈
        while (!tmp.empty() && tmp.top() > cur) {
            s.push(tmp.top());
            tmp.pop();
        }
        tmp.push(cur);
    }
```

## 三色标记DFS判断有向图环检测

```cpp
#include <iostream>
#include <vector>
using namespace std;

// dfs 返回 true 代表存在环
bool dfs(int u, vector<vector<int>>& adj, vector<int>& color) {
    color[u] = 1; // 标记为正在访问（入递归栈）
    for (int v : adj[u]) {
        if (color[v] == 1) {
            // 后继节点在递归栈里，找到环
            return true;
        }
        if (color[v] == 0) {
            if (dfs(v, adj, color)) {
                return true;
            }
        }
        // color[v]==2 跳过，已经处理完毕
    }
    color[u] = 2; // 所有子节点处理完，标记完成
    return false;
}

// 入口函数：检测整张有向图是否存在环
bool hasCycle(vector<vector<int>>& adj) {
    int n = adj.size();
    vector<int> color(n, 0); // 全部初始化为0：未访问
    for (int i = 0; i < n; ++i) {
        if (color[i] == 0) {
            if (dfs(i, adj, color)) {
                return true;
            }
        }
    }
    return false;
}

int main() {
    // 示例1：有环图 0->1,1->2,2->1
    vector<vector<int>> g1 = {
        {1},
        {2},
        {1}
    };
    cout << boolalpha << hasCycle(g1) << endl; // true

    // 示例2：无环 DAG 0->1,0->2,1->3,2->3
    vector<vector<int>> g2 = {
        {1,2},
        {3},
        {3},
        {}
    };
    cout << hasCycle(g2) << endl; // false
    return 0;
}
```

```go
package main
import "fmt"
type ListNode struct{
    Val int
    Next *ListNode
}
func mergeTwoLists(list1 *ListNode, list2 *ListNode) *ListNode {
	if list1 == nil {
		return list2
	}
	if list2 == nil {
		return list1
	}
	if list1.Val < list2.Val {
		list1.Next = mergeTwoLists(list1.Next, list2)
		return list1
	}
	list2.Next = mergeTwoLists(list1, list2.Next)
	return list2
}
func build(Vals []int) *ListNode {
    dummy := &ListNode{}
    cur := dummy
    for _, v := range Vals {
        cur.Next = &ListNode{Val: v}
        cur = cur.Next
    }
    return dummy.Next
}
func print(head *ListNode) {
    cur := head
    for cur != nil {
        fmt.Printf("%d ", cur.Val)
        cur = cur.Next
    }
    fmt.Println()
}
func main() {
	l1 := build([]int{1, 2, 4})
	l2 := build([]int{1, 3, 4})
	merged := mergeTwoLists(l1, l2)
	print(merged) // 输出：1 1 2 3 4 4
}
```
