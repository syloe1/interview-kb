## 给一个 01 串，保证开头是 0、结尾是 1，找到任意一个 “01” 子串的位置，要求复杂度尽可能低。

```cpp
// 中点是0， 01在右边区间
// 中点是1， 那么01一定在左边区间
#include <string>
int find01_binary(const std::string& s) {
    int l = 0, r = s.size() - 1;
    while (l < r) {
        int mid = (l + r ) / 2 ;
        if (s[mid]) == '0' {
            l = mid + 1;
        } else {
            r = mid;
        }
    }
    // l是第一个'1'的位置， 那么01子串起点是l-1
    return l - 1;
}
```

## 给你一个 严格递增 的整数数组 rungs ，用于表示梯子上每一台阶的 高度 。当前你正站在高度为 0 的地板上，并打算爬到最后一个台阶。另给你一个整数 dist 。每次移动中，你可以到达下一个距离你当前位置（地板或台阶）不超过 dist 高度的台阶。当然，你也可以在任何正 整数 高度处插入尚不存在的新台阶。返回爬到最后一阶时必须添加到梯子上的 最少 台阶数。

```cpp
题目理解
数组 `rungs` 严格递增，起点高度 0。每次最多向上跳 `dist`。如果相邻两个台阶高度差大于 `dist`，就需要插入新台阶，求**最少插入台阶数量**。

> 公式：两个高度 `prev` 和 `cur`，差值 `delta = cur - prev`
> 需要新增台阶数：`(delta - 1) / dist - 1`，当 `delta > dist` 才需要加。
#include <bits/stdc++.h>
int cal(vector<int>& nums, int dist) {
    int res = 0;
    int cur = 0;
    for (int h : nums) {
        int d = h - cur ;
        res += (d - 1) / dist;
        cur = h ;
    }
    return res ;
}
```

## 删除链表的倒数第N个节点

```cpp
找到倒数第n + 1节点p, 执行p->next = p->next->next
ListNode* removeNthFromEnd(ListNode* head, int k) {
    auto dm = new ListNode(-1, head);
    int n{0};
    for (auto p{dm}; p; p = p->next) n++;
    auto p = dm;
    for(int i{0}; i <n - k - 1; i++) p = p->next;
    p->next = p->next->next;
    return dm->next;
}
```
