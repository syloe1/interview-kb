索引加速数据库查询，占一部分存储空间
(1) 有序表索引：按属性值顺序存储记录
(主索引/聚簇索引) 索引比较大时，一次
①稠密索引：索引块中存放每条记录的索引属性值和指向记录的指针
②稀疏索引：每个物理块只对应一个索引项
多级索引：单一级索引完成查找
二级以及以后必须经稀疏索引
辅助索引：建立在表的非排序属性上的索引

查询处理：查询分析、查询检查、查询优化、查询执行

创建索引：
create [unique|cluster] index 索引名 on 表名 (列名 [ASC/DESC])

cluster 聚簇索引（聚集索引）

索引重命名
ALTER Index <旧索引名> Rename to <新索引名>

删除索引
DROP index <索引名>

from 表/视图别名
where 表达式
GROUP BY 列 [having 表达式] order by 列 [ASC/DESC] limit [行数] offset [行数]
