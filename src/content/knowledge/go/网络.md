#### 四层： 传输层 TCP/UDP

七层： 应用层： HTTP/HTTPS., GRPC.

- **四层负载均衡**：只看 **IP + 端口**，转发 TCP/UDP 数据包，**不拆包、不解协议**。
- **七层负载均衡**：拆开应用层协议，看 **URL、Header、Cookie、Host** 再转发，**懂业务内容**。

## 四层负载均衡（Layer 4） LVS

### 1. 工作原理

只基于：**源 IP、源端口、目的 IP、目的端口** 做转发。

- 不解析应用层数据（看不懂 HTTP 内容）
- 基于 **TCP 连接** 做调度
- 你刚才写的 **TCP 负载均衡器，就是标准四层 LB**

### 2. 流程

1. 客户端发起 TCP 连接到 LB 四层端口
2. **LB 在 TCP 握手阶段** 就按轮询 / 加权轮询选后端服务器
3. 建立 **客户端 <->LB、LB<-> 后端** 两条 TCP 连接
4. 后续所有数据包直接透传，**不拆包、不解析内容**

### 3. 特点

✅ 优点

- 性能极高、转发快、消耗低
- 只处理 TCP 层，逻辑简单
- 支持所有 TCP/UDP 业务：MySQL、Redis、SSH、自定义 TCP 私有协议

## 七层负载均衡（Layer 7） Nginx

### 1. 工作原理

**拆包解析应用层协议**

，看懂业务内容再转发。以 HTTP 为例：LB 会解析 HTTP 请求头、请求行。

### 2. 可以基于这些条件调度

- 域名 Host
- URL 路径 `/api` `/static`
- 请求 Header
- Cookie、Session
- 请求方法 GET/POST
- HTTPS 证书卸载（LB 解密）

### 3. 流程

1. 客户端和 LB 完成 TCP 握手
2. LB **接收完整 HTTP 请求、解析应用层内容**
3. 根据 URL / 域名 选对应的后端服务
4. 再向后端发起新请求，拿到响应后返回给客户端

### 4. 特点

✅ 优点

- **基于业务内容灵活分流**
- 支持动静分离、按路径路由、灰度发布
- 可做 HTTPS 证书卸载、WAF 防护、缓存
- 适合 Web 服务、微服务网关

客户端 → 四层 LVS (L4) → 七层 Nginx / 网关 (L7) → 后端服务

- 四层扛高并发、大流量
- 七层做业务路由、灰度、证书、WAF

# 、LVS 原理（Linux Virtual Server）

## 1. 本质

**内核态模块**，工作在四层（TCP/UDP），**几乎不消耗 CPU**，能扛**几十万～百万并发**。

## 2. 三种工作模式（必考、必懂）

### ① NAT 模式（网络地址转换）

- LVS 修改**目的 IP / 源 IP**
- 所有流量来回都走 LVS
- **LVS 会成为瓶颈**
- 适合小规模

### ② DR 模式（Direct Route，生产最常用！）

- LVS 只**修改目的 MAC 地址**
- 响应**不经过 LVS**，服务器直接回给用户
- **性能最高**
- 要求 LVS 和后端服务器在**同一个广播域（同一网段）**

### ③ TUN 模式（IP 隧道）

- 跨网段转发
- 用得少

## 3. LVS 特点

✅ 内核级、极快、极高并发✅ 支持 TCP、UDP、任何端口✅ 不理解 HTTP

# Nginx 原理（七层）

## 1. 本质

**用户态进程**，工作在七层（HTTP/HTTPS），**解析协议后转发**。

## 2. 工作流程

1. 与用户完成 TCP 连接
2. **接收并解析 HTTP 请求**
3. 根据 `location` / `host` / `header` 选择后端
4. 转发请求
5. 接收响应并返回用户

## 3. Nginx 能做什么（LVS 做不到）

- 根据 **URL 路由**`/api/*` → 服务 A`/static/*` → 服务 B
- 根据 **域名** 转发
- HTTPS 证书卸载
- 缓存、限流、黑白名单、WAF
- 重试、健康检查
- gzip 压缩

## 4. Nginx 负载均衡策略

- 轮询
- 加权轮询
- ip_hash（会话保持）
- least_conn
- 第三方：fair、url_hash

LVS 负责把流量分发给 Nginx 集群，Nginx 负责把请求分发给具体服务。

SDN（Software Defined Network，软件定义网络）**把传统网络「控制面」和「转发面」彻底解耦**，用软件集中控制全网，转发设备只负责无脑转发。

SDN 网络：**控制器统一管控制面**，交换机只做**转发面**，下发流表就生效，全网可编程、自动化。
