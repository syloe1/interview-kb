# 总线逻辑（SPI）

nRF24L01 是**SPI 从设备**，51 单片机作为 SPI 主机。

1. CSN 拉低：选中 nRF 模块，开启 SPI 通信
2. SCK 提供时钟，MOSI 主机输出命令，MISO 从机返回状态
3. CSN 拉高：结束 SPI 传输
4. CE：控制射频开启，配置完寄存器后，拉高 CE 才能收发无线数据包

## 引脚

> VCC（40 脚）、GND（20脚）：电源引脚
> XTAL1（19 脚）、XTAL2（18脚）：外接时钟引脚
> RST（9 脚）：复位引脚。
> PSEN（29 脚）：程序存储器允许输出控制端。
> ALE/PROG（30 脚）：在扩展外部RAM时，ALE用于控制把P0口的输出低8位地址送锁存器锁存起来，以实现低位地址和数据的隔离。
> P0 口（39脚~~32脚）：双向8位三态I/O口，每个口可独立控制。51单片机P0口内部没有上拉电阻，若输出高时为高阻态，不能正常输出高电平，因此该组I/O口，每个口可独立控制。
> P1 口（1脚~~8脚）：准双向8位I/O口，每个口可独立控制，内部自带上拉电阻，这种接口输出没有高阻态，输入也不能锁存，故不是真正的双向I/O口。
> P2 口（21脚~28脚）：准双向8位I/O口，每个口可独立控制，内部自带上拉电阻，与P1口相似

### P0 vs P1

①P0口是漏极开路，要使其输出高电平，必须外接上拉电阻，通常选择
4.7K~10K 阻值。
②P0、P1、P2几乎都用作普通I/O口使用，既可作为输入，又可作为输出。
③P3口既可用作普通I/O口，又可作为第二功能使用，比如串口、外部中
断、计数器等

## 为什么选 11.0592MHz，不是 12MHz？

为了**串口 UART 波特率精确**。
11.0592MHz 可以被串口分频系数整除，波特率无误差；
12MHz 做串口通信时，会存在波特率误差，容易乱码。

## 按下按键：**RST 直接连通 VCC**，RST 引脚被拉到高电平，单片机立刻复位。

51 单片机 RST（9 脚）：高电平复位。只要 RST 引脚维持至少 2 个机器周期的高电平，单片机就复位。复位后：PC=0000H，程序从头开始执行

## 微机原理

1. UART 串口：异步串行通信，TX/RX 两根信号线，全双工。
2. CH340 功能：USB 协议 ↔ UART 协议转换；电脑识别为虚拟 COM 串口。
3. 51 下载原理：STC89C52 是**ISP 在系统编程**，串口下载，下载瞬间需要一次硬件复位。
4. 串口交叉：TX ↔ RXD，不能直连，直连收不到数据。

## 定时器中断

- 工作方式寄存器TMOD
  > 低四位用于T0 高四位用于T1
  - Gate CT M1 M0

```
gate =0, TCON的TR0或TR1 为1 启动计时器工作
gate = 1， 还要INT0/1 为1 才启动计时器工作诺
CT选择定时还是计数 0 定时 1 计数
M1M0 设置工作方式 13位 16位 8位 T0分成两个8位
```

- 控制寄存器TCON

```
TF1 TR1 TF0 TR0
```

> TF1 T1 溢出中断请求标志位
> TR1（TCON.6）：T1 运行控制位。TR1置1时，T1开始工作；TR1置0时， T1 停止工作。
> TF0（TCON.5）：T0 溢出中断请求标志位
> TR0（TCON.4）：T0 运行控制位，
