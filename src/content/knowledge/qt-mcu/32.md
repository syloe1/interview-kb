## GPIO用到的函数

> 使用GPIO前， 必须先开APB2时钟

```c
// 1. 复位GPIO外设，把端口寄存器恢复成上电默认状态
void GPIO_DeInit(GPIO_TypeDef* GPIOx);

// 2. 复位AFIO复用功能外设
void GPIO_AFIODeInit(void);

// 3. 根据GPIO_Init结构体配置引脚模式（最核心，必用）
void GPIO_Init(GPIO_TypeDef* GPIOx, GPIO_InitTypeDef* GPIO_InitStruct);

// 4. 给结构体填充默认参数（防止野值，规范写法）
void GPIO_StructInit(GPIO_InitTypeDef* GPIO_InitStruct);

// ========== 读输入引脚 ==========
// 读取某一个引脚的输入电平，返回0或1
uint8_t GPIO_ReadInputDataBit(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin);
// 一次性读取整个端口16个引脚的输入寄存器，返回16bit数据
uint16_t GPIO_ReadInputData(GPIO_TypeDef* GPIOx);

// ========== 读输出寄存器（注意！不是读取引脚外部电平！） ==========
// 读取输出寄存器中单个bit的值（你程序设置输出的电平，不是引脚真实外部电压）
uint8_t GPIO_ReadOutputDataBit(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin);
// 读取整个端口输出寄存器
uint16_t GPIO_ReadOutputData(GPIO_TypeDef* GPIOx);

// ========== 写输出引脚（推挽/开漏输出模式才生效） ==========
// 将指定引脚置高（1），多个引脚可以 | 在一起
void GPIO_SetBits(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin);
// 将指定引脚置低（0）
void GPIO_ResetBits(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin);
// 写单个引脚，BitVal = Bit_SET / Bit_RESET，等价上面两个函数的合并
void GPIO_WriteBit(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin, BitAction BitVal);
// 一次性写整个端口16个引脚输出值
void GPIO_Write(GPIO_TypeDef* GPIOx, uint16_t PortVal);

// 5. 引脚锁定配置：锁定引脚配置，一旦锁上，下次复位前不能再修改该引脚模式
void GPIO_PinLockConfig(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin);

// 6. 事件输出配置（EXTI事件输出，比较少用）
void GPIO_EventOutputConfig(uint8_t GPIO_PortSource, uint8_t GPIO_PinSource);
void GPIO_EventOutputCmd(FunctionalState NewState);

```

## STM32中断

- 可屏蔽中断通道： EXTI, TIM, ADC, USART, SPI, I2C
- 使用nvic统一管理中断，每个中断通道有16个可编程 的优先等级

> 优先级分为抢占优先级， 响应优先级

## EXTI 外部中断

> 监测指定GPIO口的电平信号， 当其指定的GPIO口产生电平变化时， EXTI立即向NVIC发出中断申请。
> 触发方式 - 上升沿/下降沿/双边沿/软件触发
> 支持的GPIO口， 所有的GPIO口，相同的Pin不能同时触发中断
> 通道数： 16个GPIO_Pin,PVD输出， RTC闹钟，USB唤醒
> 触发响应： 中断响应/事件响应

## AFIO数据选择器

- AFIO主要用于引脚复用功能的选择和重定义
- 32中， AFIO 复用引脚重映射 中断引脚选择
